# 跨廠共用技師平板：姓名名冊修訂

2026-09-29 使用者確認：四位技師跨廠工作，沒有個人登入帳號，也不需要建立。只需知道每筆維修由哪些人處理。此文件取代前版「同廠、個人 profiles 名單」需求，不代表正式資料庫已套用。

## 需求與介面

- 共用設備只登入一次；技師選 Pak Dasir、Suwardi、Wiwit、Rudi 的姓名，不輸入個人密碼。
- 姓名使用獨立、固定 ID 的名冊，不連結 Auth 帳號、不變更既有個人帳號。
- 初次選姓名後先顯示可回報的跨廠工作；另有「我的回報」查閱實際被記錄為處理人的案件，包含已結案案件。
- 回報只選案件、填已做事項、勾處理人；可多人共同處理。案件必須顯示廠區，避免同名設備混淆。
- 「已回報工作」不是主管正式結案。已結案紀錄可查但不可再回報。
- 管理員明確勾選設備允許的廠區；空名單不能等同全廠權限。

## 執行順序與分工

1. Terra：追加 migration，獨立名冊、廠區允許名單、原子化設備設定；調整驗證、API 與 service-only RPC。
2. 主代理：設定頁不再選個人登入帳號作技師；預填四個姓名供管理員確認。平板預設工作清單與我的回報分開，顯示廠區、保護草稿與送出重試。
3. Luna：獨立檢查使用者操作與負向案例。主代理再次檢查差異並執行型別、lint、build 與可行的自動測試。
4. 正式政策整併、實際資料庫 allow/deny 測試與平板帳號配置通過後，才能部署或推進正式網域。

## 安全與資料驗收

- 設備帳號是 verified actor；選取姓名是 declared performers，不提升權限。
- service key 只存在伺服器；每次請求與 RPC 都驗證設備啟用、帳號啟用、允許廠區、名冊成員有效。
- 同一 request ID 重送相同內容只新增一次；不同內容衝突拒絕。
- 名冊更名、移除不能抹除既有姓名快照與回報關聯。
- 匿名、個人登入與停用設備不能呼叫設備專用寫入；設備不能直接改指派、接受、結案、刪除工單。
- 允許廠 A/B 可以查回報，廠 C 拒絕；姓名不存在、移除、重複、空值均拒絕。
- 「我的回報」根據 performer 關聯，而非 assigned_user_ids；包含已結案並保持唯讀。
- 快速切換/過期回應不得覆蓋目前清單；送出中禁止切人或改內容；網路不確定時保留原請求，不把同筆誤當新回報。
